# 样稿目录说明

本目录用于存放 3-5 篇真实会议新闻/通稿样稿，供 `meeting-press-release` 提炼固定口径。

建议放入：

- 机构官网新闻 2-3 篇
- 媒体报道风格会议稿 1-2 篇

建议文件命名：

- `institutional-sample-01.md`
- `institutional-sample-02.md`
- `media-sample-01.md`

样稿到位后，优先更新：

- `references/style-guide.md`
- `references/style-modes.md`

如果样稿尚未补齐，skill 先按通用规则执行。
